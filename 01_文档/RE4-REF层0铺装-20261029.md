## 3 · 启动验证步骤（需要人看着屏幕）

```
1) 启动 RE4（Steam 正常启动，不要加 -novid 之类）
2) 进到实际游玩（菜单里 REF 面板也可能出，但 Temporal Upscaler 要在渲染线程起来之后才可用）
3) 按 Insert 开 REF 面板 → 找 Temporal Upscaler 区
4) 游戏图形设置里应出现 XeSS（可能与原生 FSR 并列）
5) 看日志：<游戏目录>\re4_framework_log.txt（或 re2_framework_log.txt，见 §5 注）
   · 正常：[PluginLoader] Loading plugins... 之后不报 "Could not load PDPerfPlugin.dll"
   · 异常：报 "Could not load PDPerfPlugin.dll, TemporalUpscaler will not work" ⇒ 桥没放对/名字不对
```
